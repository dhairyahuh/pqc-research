# Results Directory

This directory stores historical logs, intermediate JSON summaries, regression test results, and plot figures generated across research phases.

## Directory Structure
- `baseline_benchmark_results.json`: Initial baseline timing measurements on the reference ML-KEM-768 implementation.
- `spacecraft_protocol_desync_results.json`: Simulation logs of satellite frame drops under implicit rejection cascades.
- `phase2/` through `phase7l/`: Phase-specific processed outputs and timing distributions.
- `phase15q/`: Twiddle corruption pilot study results and [`results/phase15q/trial_ledger.csv`](file:///Users/dhairyajain/Desktop/pqc%20research/results/phase15q/trial_ledger.csv).
- Primary verified datasets and manifests are documented in [`data/`](file:///Users/dhairyajain/Desktop/pqc%20research/data/).
