# Experiments Directory

This directory houses experimental testbeds, configuration templates, mathematical models, and campaign runners spanning Phase 1 through Phase 7.

## Subdirectories
- `baseline/`: Unhardened baseline benchmark runners and profiles.
- `configurations/`: Parameter matrices for $(k=2, 3, 4)$ ML-KEM and ML-DSA schemes.
- `fault_injection/`: Automated fault injection harnesses and campaign scripts.
- `mathematics/`: Symbolic modeling scripts and polynomial bound verifiers.
- `mlkem/` & `mldsa/`: Specialized campaign harnesses for key encapsulation and signatures.
- `phase4/` through `phase7k/`: Historical experimental setups and phase-specific campaign scripts.
- `system_model/`: Orbit-level radiation flux and SEU rate models.
