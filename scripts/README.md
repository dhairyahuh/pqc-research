# Scripts Directory

This directory contains standalone utility scripts for plotting latency distributions, generating figures, and running automated verification checks.

## Utility Scripts
- [`plot_baseline.py`](file:///Users/dhairyajain/Desktop/pqc%20research/scripts/plot_baseline.py): Plots baseline execution latency distributions for standard ML-KEM-768 operations.
- [`plot_level1_results.py`](file:///Users/dhairyajain/Desktop/pqc%20research/scripts/plot_level1_results.py): Generates comparison plots between unhardened, DMR, and TFIB-hardened execution profiles.

## Execution
```bash
python3 scripts/plot_baseline.py
python3 scripts/plot_level1_results.py
```
