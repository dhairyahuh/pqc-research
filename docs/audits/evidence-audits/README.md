# Evidence Audits

This directory contains the core evidence audits, gap closure documents, and prior-art evaluations produced during the repository audit and scientific reconciliation phases.

## Documents & Data
- [`closest_prior_art_comparison.csv`](file:///Users/dhairyajain/Desktop/pqc%20research/docs/audits/evidence-audits/closest_prior_art_comparison.csv): Systematic comparative matrix against 9 leading prior art schemes (Sarkisov 2019, Bindel 2020, Ravi 2021, etc.).
- [`contribution_analysis.md`](file:///Users/dhairyajain/Desktop/pqc%20research/docs/audits/evidence-audits/contribution_analysis.md): Rigorous assessment of novelty, defensibility, and academic contributions.
- [`experimental_gap_closure.md`](file:///Users/dhairyajain/Desktop/pqc%20research/docs/audits/evidence-audits/experimental_gap_closure.md): Audit closing the gap between exploratory pilot runs and rigorous cleanroom trials.
- [`final_contribution_decision.md`](file:///Users/dhairyajain/Desktop/pqc%20research/docs/audits/evidence-audits/final_contribution_decision.md): Final scope and contribution boundary decisions for publication.
- [`manuscript_corrections.md`](file:///Users/dhairyajain/Desktop/pqc%20research/docs/audits/evidence-audits/manuscript_corrections.md): Itemized audit of corrections applied to the manuscript text to eliminate overstated claims.
- [`research_extension_proposal.md`](file:///Users/dhairyajain/Desktop/pqc%20research/docs/audits/evidence-audits/research_extension_proposal.md): Detailed proposal for post-manuscript research phases and hardware beam testing.
- [`research_inventory.md`](file:///Users/dhairyajain/Desktop/pqc%20research/docs/audits/evidence-audits/research_inventory.md): Master inventory of all research claims, numerical figures, and underlying code/data files.
