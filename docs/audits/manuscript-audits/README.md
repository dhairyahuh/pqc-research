# Manuscript Audits

This directory maintains claim tracking, errata logs, and publication readiness checks for the academic manuscript.

## Verification Checklist
- **Statistical Fidelity:** All figures and tables in [`paper/manuscript.md`](file:///Users/dhairyajain/Desktop/pqc%20research/paper/manuscript.md) must match underlying datasets cataloged in [`data/manifests/dataset_provenance_manifest.csv`](file:///Users/dhairyajain/Desktop/pqc%20research/data/manifests/dataset_provenance_manifest.csv).
- **Anti-Hallucination Guardrails:** No claims of physical beam testing or mechanized Coq/EasyCrypt proofs are permitted without explicit qualification.
- **Version History:** Historical working drafts and backups are archived in [`paper/versions/`](file:///Users/dhairyajain/Desktop/pqc%20research/paper/versions/).
