## 2. Design

### 2.1 Deterministic SHAKE-256 PRF-based Seed Expansion
All per-trial pseudorandomness is generated by `campaign_prf()` defined in `tfib_experiments/campaign_prf.h`:

```c
static inline void campaign_prf(
    uint8_t *out, size_t outlen,
    int trial, tfib_mode_t mode, tfib_fault_locus_t locus, bool persistent
)
```

**Explicit Little-Endian Serialization (16-byte `seed_ctx`):**
| Byte Offset | Content | Serialization Format |
|---|---|---|
| `[0..3]` | `0x1337C0DE + trial * 31` | `uint32_le` via `campaign_store32_le()` |
| `[4..7]` | `(uint32_t)mode` | `uint32_le` via `campaign_store32_le()` |
| `[8..11]` | `(uint32_t)locus` | `uint32_le` via `campaign_store32_le()` |
| `[12..15]` | `persistent ? 1u : 0u` | `uint32_le` via `campaign_store32_le()` |

**Output:** `SHAKE-256(seed_ctx, outlen)` — FIPS 202 XOF expansion producing deterministic pseudorandom bytes.

**Clarification on Randomness Terminology (Remediation DEF-04):**
This mechanism is **deterministic PRF-based seed expansion**, specifically chosen to guarantee 100% reproducible fault-injection trials. It is **not** an interactive OS CSPRNG, does not consume dynamic hardware entropy, and maintains no mutable PRNG state machine.

### 2.2 Per-Trial Key Material Derivation
Each trial derives 96 bytes from `campaign_prf()`:
```
prf_output[96] = SHAKE-256(seed_ctx, 96)
  ├── seed64 = prf_output[0..63]   → d || z for KeyGen (FIPS 203 Alg. 15)
  └── seed32 = prf_output[64..95]  → m for Encaps (FIPS 203 Alg. 16)
```

### 2.3 Residual `randombytes` Symbol
A placeholder `randombytes()` function is exported to satisfy static linker requirements for `mlkem768_inst.o`. Runtime instrumentation proves it is **never called** (`g_randombytes_call_count == 0`).

## 5. Independence Audit Summary

Disassembly (`otool -tV`) of `tfib_experiment_runner` confirms that `_mlkem768_dec_monitored` is the **only** in-tree cryptographic routine invoked. All ground-truth generation is decoupled:

| Cryptographic Operation | Implementation Source | Version / Provenance |
|---|---|---|
| Key Generation | `independent_oracle_keypair_derand` | `liboqs` v0.16.0 |
| Encapsulation | `independent_oracle_encaps_derand` | `liboqs` v0.16.0 |
| Rejection Secret | `independent_oracle_compute_rejection` | FIPS 202 Reference (TweetFIPS-202) |
| Seed Expansion PRF | `campaign_prf` (SHAKE-256) | FIPS 202 Reference (TweetFIPS-202) |
| Decapsulation under Test | `mlkem768_dec_monitored` | In-tree ML-KEM-768 (`mlkem768_inst.o`) |
